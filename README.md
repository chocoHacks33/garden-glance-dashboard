# Garden Glance Dashboard

Garden Glance is a lightweight, dependency-free dashboard for reviewing houseplant health, moisture, and care locations at a glance.

Use the collection search to quickly find plants by name, type, location, or health status.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Validate

```bash
npm run check
```

The starter uses plain HTML, CSS, and JavaScript, so there is no build step or runtime dependency.
